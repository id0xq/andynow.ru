# andynow.ru

Пространство Andy Now: кто я, обучение игре на ханге, подбор инструментов, звук на событиях, цифровые продукты, проекты и журнал из канала «Музыка Сфер».

Статический сайт без зависимостей: Node 20+ собирает HTML из шаблонов в `dist/`. Хостинг — GitHub Pages, домен — andynow.ru (REG.RU).

## Команды

```bash
node build.mjs            # сборка в dist/
node build.mjs --serve    # сборка и просмотр на http://localhost:4321
node tools/telegram.mjs   # забрать новые посты канала в content/telegram/
sh tools/publish.sh "что изменилось"   # выложить на GitHub, дальше сайт собирает и публикует Actions
```

## Дизайн-код «Now»

Референс по духу — direction.zorian.studio, живое фото — вариант B сайта amber&ash. Код свой:

- **Цвета.** Белый `#FFFFFF`, чернила `#141516`, один оранжевый `#FF5A1F`, холодный ледяной серый `#ECF0F1` для подложек. Ночные секции графитовые `#121416`, с теми же токенами наоборот. Пастели нет.
- **Шрифты.** Montserrat (переменный, 100–900): в заголовках первое слово тонкое, остальное жирное. JetBrains Mono для цифр, подписей и трекеров. Literata для чтения журнала. Все OFL, лежат в `src/assets/fonts`.
- **Форма.** Названия секций между тильдой и точкой со слешем: `~ журнал ./`, как в `~ontheflow./`. Нумерованные строки 01, 02… на тонких линиях, квадратные кнопки, крупные тонкие цифры фактов.
- **Карточки.** Будто залиты прозрачной смолой или льдом: скруглённый блок, тонкая светлая кромка, блик, который идёт за курсором, глубина у нижнего края. Блок чуть наклоняется к курсору, картинка внутри смещается в обратную сторону. Класс `resin`. Эффект нарочно тихий.
- **Ледяной кейс.** Каждое фото (и карточки разделов, и видео) стоит в толстом прозрачном блоке, как сертификат zorian: светлая плита со скруглёнными углами, яркая кромка, в толще тёплый и холодный отсветы и блик, вокруг снимка фаска с цветным расколом (красный с одной стороны, синий с другой). Блок наклоняется к курсору. Разметка: `.slab` + `.glass` (`photo()` в `layout.mjs`), для карточек и видео `.ice-box`. Голое фото: класс `flat`.
- **Фото.** Все цветные, в одном кинематографичном грейде. Сразу видно размытое превью 16 px (встроено в страницу). Само фото браузер видит всегда и грузит заранее, в одном из трёх размеров; превью лежит поверх и уезжает вниз за оранжевой скан-линией за 0,6 с, когда фото пришло и стоит на экране. Потом фото медленно дышит. Прятать само фото (clip-path) нельзя: браузер тогда считает его невидимым и не грузит. На карточках подпись-трекер в моно.
- **Первый экран.** Фото Andy у моря (Пхукет, кадр DSC00134), вписанное в страницу: кадр начинается на 36 % высоты, а голова и плечи выходят из него на белое. По фото идёт скан-линия, свечение за ней маской ограничено самим фото. Три трекера (ханг, горизонт, камни) медленно плывут, их координаты живые. Четыре фразы рассыпают фото на ~46 000 цветных точек (на телефоне ~24 000), и точки стаей собираются в формы: ханг сверху с оранжевым звучащим полем (обучение), ханг в пространстве (инструменты), звуковые волны (события), куб (цифровые продукты). Потом точки летят обратно, фото проявляется, симуляция останавливается. Без WebGL остаётся фото со сканом и трекерами.

## Фото

`tools/photos.py` берёт оригиналы из `~/Downloads/Andy Photo Bank` (съёмки на Пхукете, на Алтае, в Землях Силы и другие), фото обучения и Храма Звука с handpansphere.ru, обложки каруселей Handpan Sphere для Instagram и кадры видео. Грейд один на всё (`tools/cine.py`, кинематографичный): цвет фотографа сохраняется; глубокие мягкие чёрные, плёночный завал светов, ясность в средних тонах, бирюза в тенях и янтарь в светах, живой цвет при защищённой коже, тихая виньетка, очень мелкое зерно. Пропорции исходные, кадр решает вёрстка. Обложки каруселей и картинка ~ontheflow./ идут без грейда.

`~ontheflow./` — оранжевая сфера из точек (знак магазина) в мурмурации: `tools/sphere.py` рисует её в `sources/ontheflow-sphere.png`.

Каждое фото выходит в трёх размерах (1600, 1200 и 720 px по длинной стороне, браузер берёт нужный через srcset) и с превью 16 px в `photos.json`.

```bash
python3 -m venv .venv && .venv/bin/pip install -r tools/requirements.txt
.venv/bin/python tools/photos.py                     # все фото
.venv/bin/python tools/photos.py temple-summer       # только названные
```

Первый экран: маска фигуры снята Apple Vision (`swift tools/lift.swift sources/sea.jpg cut.png sources/sea-mask.png`, macOS 14+). `photos.py` красит кадр тем же грейдом (синий мягче, небо остаётся ледяным) и собирает `hero-sea.webp` с прозрачностью: ниже `FRAME_TOP` весь кадр, выше только фигура. Чтобы сменить кадр, положите новый `sources/sea.jpg`, снимите маску и поправьте `HERO_TRACKS` в `src/pages.mjs` (места трекеров в долях ширины и высоты кадра).

## Журнал

Источники два:
1. `content/journal/*.md` — посты из архива канала (первые взяты из проекта «Музыка Сфер» скриптом `tools/journal-seed.py`). Новый пост можно добавить файлом: frontmatter `date`, `title`, `photo` (имя из `photos.json`), дальше текст абзацами.
2. `content/telegram/posts.json` — то, что `tools/telegram.mjs` читает из канала. Workflow запускает его каждый день.

**Важно:** у канала @Music_ofSpheres включено «Запретить копирование». Пока оно включено, Telegram не отдаёт текст постов наружу (ни на t.me/s/, ни во встраиваниях), и автоматический сбор возвращает пустоту. Чтобы журнал пополнялся сам: Telegram → канал → Изменить → Тип канала → выключить «Запретить копирование». Если защита нужна, новые посты добавляются файлами в `content/journal/`.

## Публикация

- Репозиторий: `id0xq/andynow.ru` (публичный, нужен для бесплатного Pages).
- Сборка и выкладка: GitHub Actions (`.github/workflows/deploy.yml`) — на каждый push в main, вручную и раз в день.
- `tools/publish.sh` синхронизирует эту папку в клон `~/.cache/andynow.ru`, коммитит и пушит, включает Pages из Actions и домен.
